# Jobs-to-be-Done Analysis

## Format
When [specific situation or trigger],
I want to [what the person wants to do / achieve],
So I can [the underlying outcome or motivation].

## Example
When a user submits a helpdesk request,
I want to know it was received and who's handling it,
So I can plan my day without worrying about whether anything is happening.
