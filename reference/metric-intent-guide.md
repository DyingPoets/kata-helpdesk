# Metric Intent — Writing Guide

## What Is Metric Intent?

Metric intent answers: **"Why are we measuring this?"**

It's the explicit link between a metric and the user value it's supposed to prove.
Without it, metrics measure activity. With it, they measure outcomes.

## The Template

> "If [metric] moves as intended, it proves that [user behaviour / outcome]."

## Examples

**Bad (activity metric):**
> "We will measure: number of tickets created per day."
> Intent: ...we delivered the feature.

**Good (outcome metric):**
> "We will measure: % of tickets created via web form vs. email."
> Intent: "If this moves from 0% to 60%+ in 30 days, it proves that support agents prefer the structured form over email, and that users find it accessible enough to use without prompting."

## The Test

If you can't complete the sentence "If this metric moves as intended, it proves ____" — you don't have metric intent. You have a number.

Common failure mode: "We'll track X so we can see if people are using it."
Fix: "We'll track X because if it [direction] by [amount] in [timeframe], it proves [user behaviour]."
